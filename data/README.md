# 데이터 안내

이 저장소에는 원본 및 가공 의료 데이터를 포함하지 않습니다. 교육용 비식별 데이터이더라도 데이터 이용 조건, 개인정보 보호, 파일 용량을 고려해 코드와 문서만 공개하는 구성을 권장합니다.

## 원천 데이터

| 파일 | 분석상 역할 | 주요 내용 |
|---|---|---|
| `EDU200` | 진료 내역 기본 테이블 | 환자·진료 건, 연령, 성별, 요양급여비용, 본인부담금 |
| `EDU300` | 병원 진료 상세 | 병원에서 발생한 투약·행위·금액·투여일수 |
| `EDU400` | 상병 내역 | 환자·진료 건별 주상병 및 부상병 코드 |
| `EDU530` | 약국 진료 상세 | 약국에서 발생한 투약·금액·투여일수 |

## 현재 프로젝트의 주요 가공 파일

원본 프로젝트 폴더의 파일명과 분석 단계는 다음과 같이 해석했습니다.

| 경로 | 역할 |
|---|---|
| `OK/200_400.csv` | 진료 내역과 상병 내역 결합 |
| `OK/200_400_no_c_r.csv` | 암·희귀/고비용 질환 등 제외 후 데이터 |
| `OK/200_400_no_c_r_m.csv` | 제외 기준 적용 후 비정신질환 비교군 |
| `OK/200_400_no_c_r_only_mental.csv` | 제외 기준 적용 후 정신질환군 |
| `c/300_no_c_r_m_f.csv` | 비교군의 병원 투약 상세 |
| `c/300_no_c_r_only_mental_f.csv` | 정신질환군의 병원 투약 상세 |
| `c/530_no_c_r_m_f.csv` | 비교군의 약국 투약 상세 |
| `c/530_no_c_r_only_mental_f.csv` | 정신질환군의 약국 투약 상세 |
| `c/c/*.csv` | 환자별 금액 집계 산출물 |
| `c/d/*.csv` | 투여일수 집계 산출물 |

`no_c_r` 등의 정확한 필터 코드 목록은 현재 폴더에 남아 있지 않습니다. 발표 대본에 따르면 암, 파킨슨질환, 크론병, 치료재료대 등 비용 편차가 큰 항목을 제외했습니다.

## 핵심 변수

| 변수 | 의미 |
|---|---|
| `MID` | 비식별 환자 식별자 |
| `JID` | 비식별 진료 건 식별자 |
| `PAT_AGE` | 범주화된 환자 연령 |
| `MAIN_SICK`, `SUB_SICK`, `SICK_CD` | 주상병, 부상병, 결합 상병 코드 |
| `RVD_RPE_TAMT_AMT` | 요양급여비용총액 |
| `RVD_SLF_BRDN_AMT` | 환자 본인부담금 |
| `RVD_INSUP_BRDN_AMT` | 보험자 부담금 |
| `AMT` | 투약·행위 금액 |
| `TOT_INJC_DDCNT_EXEC_FQ` | 총 투여일수 또는 실행 횟수 |

## 로컬 재현용 예상 구조

```text
data-root/
├── OK/
│   ├── 200_400_no_c_r_m.csv
│   └── 200_400_no_c_r_only_mental.csv
└── c/
    ├── 300_no_c_r_m_f.csv
    ├── 300_no_c_r_only_mental_f.csv
    ├── 530_no_c_r_m_f.csv
    └── 530_no_c_r_only_mental_f.csv
```

```bash
python scripts/summarize_claims.py --data-root /path/to/data-root
```

스크립트는 개인별 레코드를 출력하지 않고 그룹 수준의 집계 결과만 표준 출력으로 제공합니다.
