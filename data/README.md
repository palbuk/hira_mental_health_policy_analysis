# 데이터 안내

원본과 가공 CSV는 이 저장소에 올리지 않았습니다. 교육용 비식별 데이터이지만 데이터 이용 조건과 파일 용량을 고려해 설명 문서와 재집계 스크립트만 공개합니다.

## 원천 데이터

| 파일 | 분석상 역할 | 주요 내용 | 행 수 |
|---|---|---|---:|
| `EDU200` | 진료 내역 기본 테이블 | 환자·진료 건, 연령, 성별, 요양급여비용, 본인부담금 | 153,538 |
| `EDU300` | 병원 진료 상세 | 병원에서 발생한 투약·행위·금액·투여일수 | 1,436,664 |
| `EDU400` | 상병 내역 | 환자·진료 건별 주상병 및 부상병 코드 | 519,724 |
| `EDU530` | 약국 진료 상세 | 약국에서 발생한 투약·금액·투여일수 | 209,007 |

실제 데이터를 확인한 결과는 다음과 같습니다. EDU200은 전체 153,538행이고 고유 MID가 153,538개, 고유 JID가 1,553개입니다. MID가 행 수와 일치하므로 MID는 명세서 단위, JID는 환자 단위입니다. EDU400은 전체 519,724행에 고유 MID가 153,538개로, 명세서 1건당 상병이 평균 3.38행, 최대 42행 연결되는 1:N 구조입니다.

- MID당 JID가 2개 이상인 경우는 0건입니다. 하나의 명세서는 항상 한 환자에게 귀속되므로 MID와 JID는 명세서 단위에서 1:1입니다.
- SICK_TY_CD는 '1'(주상병) 153,079행, '2'(부상병) 365,540행, '$' 1,105행으로 분포합니다. '$'의 의미는 변수설명서에서 확인하지 못해 현재는 부상병으로 취급하고 있습니다.
- 주상병이 없는 MID는 459건이며, 주상병이 2개 이상인 MID는 0건입니다.
- EDU300에는 투약 외에 진료행위도 포함되어 있어 DIV_TY_CD로 구분해야 합니다. 투약 항목은 DIV_TY_CD가 '3'이며, EDU530은 209,007행 전부가 '3'입니다. EDU300 전체 금액을 투약비로 계산하면 실제 투약비의 12배 이상이 됩니다.

## 분석하면서 만든 파일

대회 당시 파일명이 깔끔하게 정리되어 있지는 않았습니다. 남아 있는 파일의 열과 값을 확인해 보니 각 파일은 아래 단계에서 사용한 것으로 보입니다.

| 경로 | 역할 |
|---|---|
| `OK/200_400.csv` | 진료 내역과 상병 내역 결합 |
| `OK/200_400_no_c_r.csv` | 암·희귀/고비용 질환 등 제외 후 데이터 |
| `OK/200_400_no_c_r_m.csv` | 제외 기준 적용 후 비정신질환 비교군 |
| `OK/200_400_no_c_r_only_mental.csv` | 제외 기준 적용 후 정신질환군 |
| `c/300_no_c_r_m_f.csv` | 비교군의 병원 투약 상세 |
| `c/300_no_c_r_only_mental_f.csv` | 정신질환군의 병원 투약 상세 |
| `c/530_no_c_r_m_f.csv` | 비교군의 약국 투약 상세 |
| `c/530_no_c_r_only_mental_f.csv` | 정신질환군의 약국 투약 상세 |
| `c/c/*.csv` | 환자별 금액 집계 산출물 |
| `c/d/*.csv` | 투여일수 집계 산출물 |

`no_c_r`에 사용한 정확한 코드 목록은 남아 있지 않습니다. 발표 대본에는 암, 파킨슨질환, 크론병, 치료재료대 등 비용 편차가 큰 항목을 제외했다고 기록되어 있습니다.

## 주로 확인한 변수

| 변수 | 의미 |
|---|---|
| `MID` | 명세서(진료 건) 식별자입니다. 하나의 청구명세서를 식별하며 진료·상병·처방 상세가 이 키로 연결됩니다. |
| `JID` | 비식별 환자 식별자입니다. 동일 환자의 여러 명세서를 묶는 키입니다. |
| `PAT_AGE` | 범주화된 환자 연령 |
| `MAIN_SICK`, `SUB_SICK`, `SICK_CD` | 주상병, 부상병, 결합 상병 코드 |
| `RVD_RPE_TAMT_AMT` | 요양급여비용총액 |
| `RVD_SLF_BRDN_AMT` | 환자 본인부담금 |
| `RVD_INSUP_BRDN_AMT` | 보험자 부담금 |
| `AMT` | 투약·행위 금액 |
| `TOT_INJC_DDCNT_EXEC_FQ` | 총 투여일수 또는 실행 횟수 |

## 재집계 스크립트 실행

```text
data-root/
├── OK/
│   ├── 200_400_no_c_r_m.csv
│   └── 200_400_no_c_r_only_mental.csv
└── c/
    ├── 300_no_c_r_m_f.csv
    ├── 300_no_c_r_only_mental_f.csv
    ├── 530_no_c_r_m_f.csv
    └── 530_no_c_r_only_mental_f.csv
```

```bash
python scripts/summarize_claims.py --data-root /path/to/data-root
```

스크립트는 개인별 행을 출력하지 않고 그룹별 합계와 평균만 보여줍니다.
